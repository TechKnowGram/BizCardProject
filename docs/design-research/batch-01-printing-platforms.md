- **Patterns to Avoid:**

## Batch 1 Synthesis & Key Lessons for BizCard

### Top 3 Benchmark Sites from Batch 1
1. **MOO**: Best for brand prestige, luxury finish representation, and multi-employee variations (Printfinity).
2. **Canva**: Best for intuitive constrained editing and docked print-checkout drawers.
3. **UPrinting**: Best for instant dynamic pricing, automated file checking, and prepress proofing.

### Critical UX Features to Implement in BizCard
1. **Docked Specification Inspector**: Rather than cluttered cards, adopt a right-docked or modal inspector for card quantity, finish, and payer (Company vs Individual).
2. **Interactive Front/Back Card Switcher**: Single-click flip with real-time vector canvas rendering.
3. **Automated Safety & Trim Guides**: Visual dotted lines showing bleed zones so cards never print with cut-off text.
4. **Volume Pricing Matrix**: Displaying transparent unit costs (`৳50/card` scaling down for bulk orders).
