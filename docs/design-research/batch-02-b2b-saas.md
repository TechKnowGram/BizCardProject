## Batch 2 Synthesis & Key Lessons for BizCard

### Top 3 Benchmark Sites from Batch 2
1. **Linear**: Best for data density, keyboard-first navigation, and surface elevation ladders without muddy shadows.
2. **Stripe**: Best for typographic luxury (light display weights, tabular numbers) and single-voltage primary button discipline.
3. **Vercel**: Best for clean horizontal sub-navigation tabs, status dot indicators, and monochromatic enterprise authority.

### Critical UX Features to Implement in BizCard
1. **Eliminate Saturated Color Chaos**: Restrict primary brand color to ONE high-leverage interactive voltage; use neutral slates (`#0F172A`, `#F8FAFC`) for surfaces.
2. **Tabular Numerals (`tnum`)**: Enforce `font-variant-numeric: tabular-nums` on all quantities, order prices (`৳50`), and employee IDs (`BSH-1001`).
3. **Structured Top & Sub-Navigation**: Clean persistent header with horizontal tab strip for dashboard sections.
4. **Floating Batch Action Bar**: When selecting multiple employees for card generation, float an action dock rather than hiding buttons in awkward table headers.
